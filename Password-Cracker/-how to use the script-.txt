>run cmd as admin

>enter: [cd "-Path of main-"]

>enter: [python install.py]

>interactive mode:
[python password_cracker.py]

>non-interactive example:
[python password_cracker.py --hash <hash> --wordlist wordlist/rockyou.txt --maxlen 5]

>Disable multiprocessing (optional):
[python password_cracker.py --no-mp]

>Set output folder (optional):
[python password_cracker.py --output-dir "-Custom path and name for your cracked results-"]

>To limit how many wordlist lines get checked (optional):
[python password_cracker.py --max-lines -no.of.lines-]

>Watch mode (live monitoring):
[python password_cracker.py --watch --watch-folder incoming_hashes]

>Safety defaults:
- Wordlists must be inside wordlist/ unless you pass --allow-external-wordlist
- API is local-only by default (see README for details)
